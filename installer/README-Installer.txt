傻龙插件安装包

安装方法：
1. 双击 Install.cmd，或直接运行 CodexDragonQuotaWidget-Setup.exe。
2. 安装位置为：%USERPROFILE%\plugins\codex-dragon-quota-widget
3. 安装程序会创建桌面和开始菜单快捷方式，并注册随 Codex 启动。
4. 如果电脑已安装 Codex CLI，安装程序还会自动注册 personal marketplace 插件。

卸载方法：
从开始菜单选择“傻龙插件 → 卸载挂件”。

说明：
- 程序为 Windows x64 自包含版本，不要求预装 .NET 8。
- 本地额度数据来自 Codex 会话事件，不会读取登录凭据。
- 未签名的本地安装程序可能触发 Windows SmartScreen 提示。
